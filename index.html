Alur Kerja Fragma

1. Masuk dan Pilih Project
Masuk ke akun Anda, buat atau pilih ruang kerja project agar perangkat, grafik, dan otomasi tertata terpisah per proyek.
2. Daftarkan Perangkat
Tambahkan perangkat baru dan terima API key langsung. Kirim JSON telemetri dari ESP32, Arduino, Python, atau cURL ke endpoint data.
3. Visualisasi dan Otomasi
Susun Line Chart, Value Card, dan Gauge Meter di halaman Visualisasi serta aktifkan logika IF/SET/ALERT di halaman Otomasi.
