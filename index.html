How Fragma Works

Create Entity
Define your device entity and the fields it emits (e.g. temperature, humidity, voltage). You instantly receive a secure device API key.
Connect Device
POST JSON telemetry directly from ESP32, Arduino, Raspberry Pi, Python scripts, or curl requests with a single HTTP header.
Visualize Telemetry
Add Line Charts and Value Cards to your entity dashboard. Live polling updates your sensor readings seamlessly in real-time.
