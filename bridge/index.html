Dokumentasi endpoint

Halaman ini memakai dua sumber data: API publik Open-Meteo untuk cuaca, dan endpoint contoh di server Fragma. Keduanya dipanggil dengan fetch() dan async/await, lalu dibaca sebagai JSON.

GET https://api.open-meteo.com/v1/forecast

Cuaca saat ini tanpa autentikasi. Tidak perlu API key.

Parameter Tipe Keterangan
latitude Float Lintang lokasi (contoh: -6.2088 untuk Jakarta).
longitude Float Bujur lokasi (contoh: 106.8456).
current String CSV Data yang diminta: temperature_2m, relative_humidity_2m, surface_pressure, wind_speed_10m, weather_code.
timezone String Zona waktu, contoh Asia%2FJakarta.
Contoh cURL:
curl -s "https://api.open-meteo.com/v1/forecast?latitude=-6.2088&longitude=106.8456&current=temperature_2m,relative_humidity_2m,surface_pressure,wind_speed_10m,weather_code&timezone=Asia%2FJakarta"
GET api/gateway.php

Daftar sensor contoh dari server Fragma. Parameter scenario dipakai untuk menguji tampilan.

Parameter Tipe Hasil
scenario=normal String HTTP 200 dengan 4 sensor aktif.
scenario=empty String HTTP 200 dengan daftar sensor kosong.
scenario=error String HTTP 500 dengan pesan galat JSON.
scenario=delay String Respons tertunda 2 detik untuk melihat tampilan loading.
Contoh cURL:
curl -s "http://localhost/fragma/api/gateway.php?scenario=error"
